# 广东扩展城市资料来源（D 组）

对应 `prototype/data/hot-cities-d.json`：10 城、100 个独立目的地。现有九城的资料核对日期保持 2026-10-27；本次新增梅州核对日期为 2026-10-31。

## 使用与核对范围

- 页面文案按旅行使用场景重新组织，来源链接用于核对地点、行政区划、文化背景和交通入口。政府旧介绍保留其原始发布日期；核对日期表示本地条目整理时间，不等同于来源发布日期。
- 票价、班次、具体开放时刻和临时活动不作为固定承诺；出行前查询铁路 12306、机场、场馆和景区当期公告。规划文件只辅助地点与资源背景，不能证明规划项目已运营。
- 城市覆盖其所辖县市，县域景点不能当作城区短途。梅州五指石在平远县、神光山在兴宁市、百侯和泰安楼在大埔县；梅县机场现址在梅江区三角镇，迁建规划不用于导航。
- 坐标为地点级展示参考，梅州部分参照高德地点页并作小数位简化，存在地图坐标系与入口差异；不用于精确测距、边界判断或直接驾车导航，用户应按全名核对正式入口。
- 独立目的地按整座景区、古镇、海岛或场馆计数：内部寺院、院落、广场、栈道和分馆不重复增加；梅州的叶帅故居并入纪念园、客家小镇并入客天下、松口码头并入古镇。
