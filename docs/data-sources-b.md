## 易变事实与已做取舍

- 福州：原维基导游交通章节可能滞后。另核查福州市政府2025-09-29滨海快线开通报道，采用机场与福州站连接事实，不写票价、时长或首末班。福州烟台山明确归于仓山，避免混入山东同名景点。
- 南昌：Wikivoyage省博条目仍提及旧址与新馆在建，明显过时，未采用其地址或把省博列入本组景点。八一起义纪念馆另用南昌市政府专题介绍核查；不采用2020年临时防疫开放公告。八一广场和起义纪念馆作为不同地点。
- 黄山：区分屯溪中心城区、汤口南大门、黄山风景区和黟县宏村/西递。核查管委会、官方旅游平台和市政府客运信息，只保留设施与换乘方向；不保留过去公告中的活动价、班次、二次入园时限或季节开放时间。山峰轮休、索道停运和山地天气须临行确认。
- 武汉/重庆/广州：城市页把景点分到分区页，景点来源直接列相应分区。地铁只写稳定站点方向，未采纳页面中旧价格或首末班。跨江、高差与大公园的距离单独提醒。
- 桂林：不采纳页面中旧票价、非正规船只进入景区等建议；象鼻山不声称需买旧版门票。河流汛情、游船和竹筏运营不在本次实时核查范围内。
- 其他城市：机场和主要铁路站名称用于行程规划，不保证所有车次停靠，也不将指南中的旧班车号作为当天可乘承诺。展馆预约统一提示前往馆方当前渠道核对，不承诺免预约、免费或随到随进。
