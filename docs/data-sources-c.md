## 内容边界与易变事实

- **不提供实时数据**：未录入具体门票、餐饮价格、列车车次、机场巴士时刻、首末班或精确开放时刻，不提供实时天气。`verifiedAt` 表示资料整理日期，不代表当日运营保证。
- **预约与活动**：博物馆闭馆、景区实名预约、演出、索道、观光电梯、游船、玻璃设施、雪雕和冰雪大世界均可能调整。文案要求按对应场馆的官方公告确认，不使用旧旅行指南中的限流人数、特定票型金额和固定洞窟数。
- **交通更新**：兰州中川机场 T3 与中川机场东站采用 2025 年已投运官方报道；济南地铁 3 号线二期采用 2025 年政府资料所述已运营事实。济南新综合交通中心、T2、济滨高铁机场站等建设计划没有作为已投入运营设施写入；航站楼至地铁的具体接驳留给当日指引。
- **来源局限**：部分 Wikivoyage 条目更新较旧，尤其小交通、店铺、票价与开放安排；只提取稳定地名、景点主题、城市空间和主要枢纽。本次尝试直接打开莫高窟、布达拉宫官网时获取超时，故没有将失败页面列入数据 sources，也没有宣称核实当前预约窗口、票型或规则。
- **风沙与高原**：敦煌的防晒、饮水、防风沙和天气调整是保守出行安排，不预测具体天气；拉萨只给节奏、休息与及时求助提示，不提供药物、治疗或保证无高原反应的建议。哈尔滨的防护和冰面提醒以文旅部安全提示交叉核对，不搬用其中过时热线与医疗细节。
- **饮食**：foods 与 foodGuide 一一对应，说明常见食材、口感和点餐方式；具体餐馆做法、时令、配料和分量需点单前确认。不推荐未经检验的野生食品，不把普通食物写为功效或治疗。
- **坐标与空间**：坐标为近似地理定位，用于城市距离与地图展示，不是经过测绘的入口点，也不是 GCJ-02 导航坐标。保留原目录的太原、沈阳、哈尔滨、兰州城市坐标、主题、消费档和画面名；新增城市与所有景点沿用已有的 city/town/coast/garden/mountain 画面名。
- **建议而非产品**：三日行程和游玩时长为编辑建议，无预约和实际路况保证。张家界第三天选择洞或湖，拉萨第三天宫殿后是否加园林视状态决定，大连第二天组合海洋公园时建议减项或延住。
