# 热门目的地资料发布记录 · 2026-10-21

本轮按用户确认的优先级先做热门城市深度资料，尚未覆盖全国所有城市。

- 城市：36 座；景点：144 处；可独立抽取目的地总计 180。
- 每条有来源、整理核对日期与近似地理坐标，按城市组织美食、季节、抵达与市内交通。
- 景点有独立游玩介绍、抵达方式、游玩时长及提示；不会套用城市多日行程。
- 删除未经证实的演示消费区间，预算输入明确排除费用未知项。
- 旧收藏、旅程、历史与房间结果按稳定 ID 补充新资料，自填内容及完成状态保留。
- 旅行文字许可、来源和局限见 prototype/data/LICENSE.md 及 docs/data-sources-a/b/c.md。

## 发布前验证

- 97 项 Node 规则、数据契约、HTTP、持久化并发、静态导出和安全渲染检查通过。
- 原界面 7 组流程、多人界面 7 组并发/延迟回归通过。
- 新旅行资料 5 组手机流程通过：覆盖数、旧记录升级、城市详细资料和来源、景点专属交通、长名称窄屏及费用未知解释。
- 最终构建及独立审查通过，未解决 P1/P2 为零。编译后的本地 Worker + D1 四组接口检查通过，实际 API 返回36城144景点、99个不同来源链接。公开跨域浏览器检查随本次发布执行，具体部署状态以 Sites 和 GitHub 发布记录为准。

## 保留限制

资料由列明来源人工核查整理，不是实时商旅供应数据。班次、票价、余票、天气、临时开放、预约余量请使用运营方最新信息。坐标只用于大致地理距离，不是导航入口；地图跳转按地点名称查询，避免混用坐标体系。部分景区官网在核查网络中无法直接读取，未把其当前规则当作已核验事实，具体见各组来源文档。

入口沿用 https://wenzo-zwz.github.io/suixing-chufa/ 。源代码在 main，静态网页在 gh-pages，多人服务沿用现有 Sites Worker 与 D1，无数据库结构变更。

独立审查发现并修复：旧目录的未抽轮次会保留旧预算候选。现在载入时按当前资料重算，变化时更新版本并取消准备；房间读取通过原 CAS 持久化，已抽结果仍保持幂等。新增三项回归覆盖双读取并发迁移、旧预算拒绝与既有结果不变。
