# 新增城市资料 f 组：内陆文化与山水

核验日期：2026-10-27。数据文件：`prototype/data/hot-cities-f.json`。本文件记录10个新城市、每城10个独立目的地，共100景；110条城市/景点记录均带 `verifiedAt: 2026-10-27`。

## 实查方法与时效边界

- 本轮使用联网搜索与网页打开核对政府、文旅部门、博物馆、景区和地方官方媒体资料；页面标题与实际返回的URL用于引用，没有按站点规律拼接页面地址。政府名录用于地点归属，专页与正式导览用于文化内容及接驳背景。部分政府网页正文抓取超时，搜索索引可读；格凸河另补已打开的贵州广播电视台正文，避免仅依赖失效正文。
- Wikivoyage用于城市交通、气候及部分稳定地点背景；所有相关引用逐条标注 `license: CC BY-SA 4.0` 与 `attribution: Wikivoyage contributors`。不采用其中旧票价、班次、公交票制和可疑优惠信息。文字为本轮中文重述与行程组织建议，不是官网原文复制。
- `verifiedAt`表示本轮资料核对日期，不能承诺当天全部景区、展厅、船班、索道或山路实时运营。预约、开闭园、天气、汛情、演艺和交通以出行当日官方公告为准；数据没有固定实时票价、班次、预算或天气预报。
- 坐标用于目的地区域定位与距离检查，表示主景区或开放片区附近，不保证为实时检票口、车辆入口或精确步行起点；大型山地及多片区景区须按官方入口导航。所有建议时长均为规划余量，长途接驳另注明。
- 每城三日行程是分区选择，不承诺三日走完全部10景。寺院、馆区与演艺规则分别核对；未将古城门楼、同园雕像、单馆展厅或同一山岳金顶拆分凑数。

## 核验中处理的关键变化与归属

- 天水麦积山机场2025年停航后已于2026年6月恢复运行，使用甘肃官方转载复航报道更新；中梁迁建机场未作为现运营到达点。秦州老城、麦积城区和南部山地分开规划，武山、甘谷、秦安各属独立县域线路。
- 宜昌北站于2025年12月26日投入运营，采用2026年宜昌市政府运营报道，铁路说明同时保留宜昌东站。三峡大坝、三峡人家分别为独立景区；屈原故里在秭归，与坝区隔江且需道路交通，不把相望写成步行相邻。
- 张掖鼓楼在所查资料中有修缮信息，本组不收录。七彩丹霞与冰沟丹霞是不同入口的独立景区；张掖大佛寺与馆内展览整体计一景。肃南地域狭长，祁丰文殊寺在行政辖区西端，更宜从酒泉方向衔接，绝非马蹄寺附近。
- 乐山市包含代管峨眉山市，峨眉山整体计一景，金顶未另拆；乐山大佛景区内部寺院和平台也未另拆。航空以成都双流/天府转铁路为入口，没有把规划机场写成现有航点。
- 安阳殷墟及殷墟博物馆整体计一景，中国文字博物馆两馆不拆；红旗渠与林州太行大峡谷虽为联合5A品牌，属相距明显、分别经营的两大主景区，文化和旅游部专页明确列出两者。
- 遵义城区、仁怀茅台、赤水、绥阳、湄潭分方向组织，赤水需独立住宿；赤水大瀑布与丙安古镇为不同完整目的地，未拆分同一瀑布平台。
- 安顺黄果树含大瀑布/陡坡塘/天星桥整体计一景，龙宫各洞与码头不拆；天龙含可选天台山整体计一景，云峰的村寨群整体计一景。
- 柳州柳侯公园含柳侯祠、程阳八寨含永济桥均整体计一景，程阳位于三江远郊，建议留宿；中渡在鹿寨县，另留公路接驳。
- 襄阳古城含北街/夫人城/昭明台周边整体计一景，古隆中内牌坊草庐不拆；博物馆使用城南新馆定位提示，未沿用旧馆址。南漳县水镜庄与春秋寨需独立长线安排。
