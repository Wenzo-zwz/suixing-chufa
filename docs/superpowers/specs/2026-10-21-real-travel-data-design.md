# 热门目的地真实资料设计

用户已选择先做热门城市、资料尽量详细。本轮沿用既有网页、筛选和多人房间架构，更新资料及必要的展示，不引入付费 API 或账号。

- 首批 36 个城市，每城 4 个市内或周边景点，总共 180 个可独立抽取目的地。保留原城市和十二个景点 ID，以兼容收藏和房间记录。
- 城市增加美食解释、主要机场和车站、市内交通、适合季节、停留建议、简短行程与注意事项。景点说明独立玩法及从所在城市如何前往。
- 优先使用文旅部门、政府、景区官网与可复用旅行指南。逐条保存来源链接和核对日期；使用 Wikivoyage 衍生内容时随资料标注 CC BY-SA 4.0 与贡献者链接。
- 删除没有依据的演示消费数值，未知费用显示尚无可靠参考。价格、班次、营业和天气不冒充实时信息。预算过滤保留，费用未知时明确排除原因。
- 增加来源、覆盖数量和交通查询入口，标签写明资料范围，不声称全国全量覆盖。交通链接使用 HTTPS，并验证网址、转义所有外来文字。
- 原等概率规则、四种手势、多人并发与唯一结果规则保持。历史收藏中旧快照按 ID 从当前目录补充新资料，保留自定义目的地兜底。

数据分成三个独立 JSON 文件；catalog.mjs 组装并校验父子关系，UI 只消费既有 API 返回的目的地对象。主流程不增加外部网络依赖。

验收：36 城市、144 景点均有有效坐标、独立文字和来源；每个出发城市附近能找到已收录地点；美食、交通、来源在手机结果页可见；旧收藏可升级；静态导出不含服务端数据；原规则、多人界面回归和公开跨域双浏览器流程通过。
